Uni Reservasi - Hotel Apartement

Fullstack Web Development

A hotel apartement booking website that allows users to explore rooms, check availability in real-time, and make reservations easily. Built with a modern stack and integrated with Supabase for database, authentication, and storage.

Live Demo

About Project

This Project was built to provide a smooth and modern booking experience for hotel apartement guests. The system includes room management, real-time availability, and a simple booking flow.

The project helped me strengthen my skills in both frontend and backend development, as well as working with real databases and authentication.

Key Features

Browse rooms with details and photos

Real-time room availability

Reservation / booking system

User authentication

Admin dashboard for managing rooms & bookings

Image upload with Supabase Storage
